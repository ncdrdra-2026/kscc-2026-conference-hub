# KSCC 2026 Conference Hub

Static public website for the KSCC International Conference 2026 schedule prototype.

## Pages

- `index.html` — public landing page.
- `agenda.html` — standalone schedule search, bilingual-discussion translation design, and recording-workflow prototype.

## Publish

The GitHub Actions workflow in `.github/workflows/deploy-pages.yml` deploys the repository root to GitHub Pages after a push to `main`. In the repository settings, select **Pages → Build and deployment → GitHub Actions** once.

No speech, translation, upload, account, or database service is connected. Do not present the demo captions or upload queue as an operational translation or recording system.
